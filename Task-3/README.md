# CODSOFT Data Analytics Internship – Task 3

## 📊 Data Visualization – Airline Passenger Satisfaction

This project is part of my **Data Analytics Internship at CODSOFT**.

The main objective of this task is to create meaningful and easy-to-understand visualizations using Python libraries such as **Matplotlib and Seaborn**.

## 🎯 Objective

- Create meaningful data visualizations.
- Understand trends and patterns in the dataset.
- Analyze relationships between different variables.
- Create different types of charts.
- Customize charts with titles, labels, legends, and colors.
- Present insights through clear and easy-to-understand visualizations.
